Інноваційний транспорт

Безпілотні шатли, єдиний цифровий квиток і швидкі пересадки зменшують затори та викиди.

Факт (Київ): станція метро «Арсенальна» — одна з найглибших у світі; модернізація ліфтів і ескалаторів пришвидшить пересадку для пасажирів.

Сучасна архітектура

Будинки з «розумними» фасадами: сонячні дахи, автоматичне затінення й озеленення для комфорту та економії енергії.

Факт (Україна): інноваційні кластери на кшталт Unit.City формують екосистему для технологічних рішень у міському просторі.

Екологічні рішення

Міські сади, дощові садки та сортування «за замовчуванням» допомагають відновлювати природу в межах міста.

Мій промпт:

Зроби структуру вебсторінки на тему «Місто майбутнього». Сторінка повинна містити такі частини: Hero, навігацію з якірними посиланнями, три змістові розділи, міні-галерею, інтерактивну частину (JavaScript без бекенду), footer і секцію «Як я використовувала ШІ». Кожна секція має мати власний id, щоб можна було легко змінювати стилі. Тексти мають бути написані зрозумілою українською мовою у вигляді логічних абзаців. Для зображень додай атрибут src, але без посилань — я додам їх сама. Назва сторінки — Lymar Diana and Sirman Suzanna_CityFuture. JavaScript-частина повинна бути простою: наприклад, інтерактивна форма або опитування, яке працює без бекенду. Код HTML, CSS і JavaScript потрібно об’єднати в один файл (без окремих підключень). Стиль оформлення — мінімалізм із двома гармонійними кольорами, hover-ефектами і адаптивністю для телефонів. Розмітка має бути семантично правильною — з тегами header, nav, main, section, footer. У міні-галереї має бути 3–4 зображення, а в основних розділах — два локальні факти про Україну, пов’язані з майбутніми технологіями, архітектурою чи екологією.
